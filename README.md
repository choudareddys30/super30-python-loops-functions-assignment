## Assignment description

Twenty beginner Python exercises using conditions, for loops, nested loops,
while loops, functions, lists, and dictionaries. Each program runs independently.

## Setup and run

Install Python 3. No third-party packages are required.
Extract this project and open its folder in VS Code. Open a terminal in that folder.

```bash
python --version
python "01-Number_Analyzer_using_for_loop.py"
python "20-Student-Registration-System.py"
```

On Windows, use `py` if `python` is unavailable. On macOS/Linux, use `python3`.
Run one file at a time and follow its prompts. Use each menu's Exit option to stop.
